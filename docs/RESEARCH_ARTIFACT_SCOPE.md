# WebStateCheck: public artifact scope

**Status:** Independent unpublished technical report (v1.1, 19 November 2026). Not peer reviewed.

The public repository provides the original testing infrastructure, example plans,
selected methods protocols and the controlled buggy/fixed browser fixture.

The historical Final Form, Axios and p-queue reproductions used separate pinned
source checkouts/bundles. The public repository does **not** include those upstream
checkouts, full private evaluation logs, or a sealed prospective benchmark.
Thus a passing public checkout test suite is an infrastructure regression result,
not an independent reproduction of every historical bug pair.

The p-queue factorial diagnostic yielded one distinct observed timing/profile
condition with a before/after difference (with repeats). These are not multiple
independent defect discoveries. The LLM pilot was exploratory and context contaminated.

**Paper:** [WebStateCheck: Timing-Aware Test Programs for Asynchronous JavaScript](WebStateCheck_Technical_Report_Updated_2026.pdf), Ouassim Lahraoui, 2026.
